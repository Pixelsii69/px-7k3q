What is PIXELS CODE?

PIXELS CODE is a custom linguistic encoding system created by Pixels.

It was designed to transform ordinary English text into a unique coded format that looks completely different from the original message.

Unlike traditional text translators, PIXELS CODE uses its own custom encoding and decoding rules to convert messages between English and Pixels Code.

This website now includes three independent versions: V2.1, V3.0 and V3.1 (Simple / Notebook Edition). Switch between them from the Translator page.

How Does It Work?

All versions have two main operations:

1. EncodingEnglish → Pixels Code

The system takes an English message and processes it using its custom encoding rules, producing a coded output.

2. DecodingPixels Code → English

The system processes the coded message in reverse, reconstructing the original English text.

Versions

V2.1PX2 header

English letters and common punctuation. Uses a custom alphabet, positional shifts, word rotations, a word counter and a checksum.

V3.0PX3 header

A separate engine with its own 257-symbol library, multi-key mathematics, position-based rules and layered verification.

V3.1 · SimplePXN header · Notebook Edition

A simplified, handwriting-friendly version of V3.0. It uses only letters and a few easy symbols, so you can write the whole message in an ordinary notebook. It has its own engine, separate from V2.1 and V3.0.

New in V3.0: it can convert text in both English and Arabic, plus numbers, symbols, emojis and other Unicode text. It also preserves spaces and line breaks exactly.

New in V3.1: built for notebooks. No chess pieces, emojis, drawings or digits in the output, just easy-to-write characters. English and Arabic are both supported, and decoding gives back the exact original text.

V3.1 — Notebook Edition

  • PurposeV3.0 uses symbols that are hard to draw by hand (like chess pieces). V3.1 fixes that so you can encode and decode messages manually in a notebook.
  • FormatEvery message looks like PXN/[ENCODED DATA][CHECKSUM], with no spaces between characters.
  • Allowed charactersA–Z and / ( ) [ ] < > # $ @ √ π % ∆ \ Π | ~ (44 characters in total).
  • LanguagesEnglish and Arabic, plus numbers, punctuation, spaces and multiple lines. Arabic is never translated or reversed.
  • How it worksThe text is converted to UTF-8 bytes, each byte goes through a reversible position-based transformation, then is written as exactly two characters from the 44-character alphabet. The last two characters are a checksum.
  • VerificationWhen decoding, the checksum is checked. If it fails, you get a checksum error instead of text.

System Features

  • PX2 / PX3 / PXN HeaderIdentifies the version: PX2 for V2.1, PX3 for V3.0 and PXN for V3.1.
  • Word / Character CounterTracks the number of words (V2.1) or characters (V3.0 and V3.1) in the message.
  • ChecksumProvides a verification value for checking message consistency.
  • Custom TransformationsUses its own set of linguistic and positional transformations.
  • Reversible EncodingAllows encoded messages to be converted back into their original text.

A Few Things to Know

PIXELS CODE is a personal experimental project created for fun and educational purposes.

It is NOT a professional encryption algorithm and does not provide real cryptographic security.

Do not use it to protect passwords, private information, or sensitive data.

It is simply a creative coding project made to be shared and enjoyed by everyone.
